Roteiro de Testes · Quarkus REST

Como testar o projeto, passo a passo

Siga na ordem. Em cada teste há o comando, o resultado esperado e um quadradinho para marcar. Se algo não bater, use a tabela de problemas no final.

Projeto: quarkus-getting-started

1Preparação

Use dois terminais PowerShell. O Terminal A fica com a aplicação rodando (não feche). O Terminal B executa os testes. No PowerShell use sempre curl.exe (com .exe), nunca só curl.

Terminal A: subir a aplicação (com o proxy da rede)

$uri = [uri]$env:HTTPS_PROXY
$env:PROXY_USER = $uri.UserInfo.Split(':')[0]
$env:PROXY_PASSWORD = [uri]::UnescapeDataString($uri.UserInfo.Split(':')[1])
cd "C:\Users\rafael-ioppi\exercicio 1\quarkus-getting-started"
& "C:\Users\rafael-ioppi\apache-maven-3.9.9\bin\mvn.cmd" quarkus:dev

Espere aparecer Listening on: http://localhost:8080. Não use .\mvnw.cmd (erro 407 no proxy).

  • Aplicação no ar, sem erros vermelhos no Terminal A

2Testes que já devem funcionar

Todos no Terminal B.

Teste 1: lista de produtos (sem filtro)

curl.exe http://localhost:8080/products

Esperado: JSON com 3 produtos (ids 1, 2 e 3).

  • Vieram os 3 produtos

Teste 2: filtro por categoria

curl.exe "http://localhost:8080/products?category=Category 1"

Esperado: só o produto 1. Atenção: a comparação diferencia maiúsculas de minúsculas.

  • Veio só o Product 1

Teste 3: filtro por preço mínimo

curl.exe "http://localhost:8080/products?minPrice=15"

Esperado: produtos 2 (20.0) e 3 (300.0).

  • Vieram os produtos 2 e 3

Teste 4: os dois filtros juntos

curl.exe "http://localhost:8080/products?category=Category 3&minPrice=100"

Esperado: só o produto 3. Teste também minPrice=500 com a mesma categoria: deve voltar [].

  • Produto 3 no primeiro e lista vazia no segundo

Teste 5: REST Client de usuários (API externa)

curl.exe http://localhost:8080/local-users

Esperado: 10 usuários (id, name, username, email) vindos de jsonplaceholder.typicode.com.

  • Vieram 10 usuários

Teste 6: REST Client de posts

curl.exe http://localhost:8080/local-posts/1
curl.exe http://localhost:8080/local-posts/5

Esperado: um objeto com id, userId, title e body, com o id pedido.

  • Post 1 e post 5 retornaram corretamente

Teste 7: configuração por linha de comando

Pare a aplicação (Ctrl+C no Terminal A) e suba de novo apontando para uma URL errada:

& "C:\Users\rafael-ioppi\apache-maven-3.9.9\bin\mvn.cmd" quarkus:dev "-Dorg.acme.IUserClient/mp-rest/url=https://url-que-nao-existe.invalid"
curl.exe -i http://localhost:8080/local-users

Esperado: erro 500. Isso prova que o -D vence o application.properties. Volte a subir normalmente depois.

  • Deu erro com a URL falsa e voltou ao normal sem ela

Teste 8: log em arquivo (extra)

Get-Content "C:\Users\rafael-ioppi\exercicio 1\quarkus-getting-started\target\quarkus.log" -Tail 20

Esperado: linhas de log recentes, incluindo a inicialização da aplicação.

  • Arquivo existe e tem conteúdo
